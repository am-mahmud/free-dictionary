# 📖 Free Dictionary
A simple, elegant, and fast online dictionary web app built with HTML, CSS, JavaScript, Tailwind, DaisyUI, and the Free Dictionary API.

## 🚀 Features
#### Word Search
- Search any English word.
- Fetches real-time definitions using the Free Dictionary API.
#### Displays
- Word
- Phonetics
- Part of Speech
- Definition

####🕒 Live Date Display
- Dynamically shows the current day, month, date, and year.
- Updates automatically every second.

#### 🎨 Modern UI
- Designed using: TailwindCSS,DaisyUI, Custom CSS and Fully responsive layout.

#### ❌ Error Handling
- If a word is not found, a friendly message is displayed.

## 🛠️ Tech Stack
